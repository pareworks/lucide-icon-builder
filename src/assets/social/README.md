# Social icon assets

These 26 monochrome SVGs were exported from [Social Media Icons & Logos (Community)](https://www.figma.com/design/vLLJskmSRUdnoxnv4U4TPU/Social-Media-Icons---Logos--Community-?node-id=0-1).

The SVG files preserve the original exports. The renderer substitutes their white fills with the selected icon colour and namespaces clip-path IDs per instance. These are filled logos, so Lucide stroke controls do not apply.
